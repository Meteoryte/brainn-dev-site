Registry Atlas

A source map for AI coding agents.

The atlas is the knowledge foundation behind RegistryRouter MCP. It helps agents identify the right registry, package index, documentation source, marketplace, catalog, or approval path before implementation begins.

Open full reference Use through MCP
Why it exists

Agents need source judgment before code judgment.

The full reference is intentionally broad. This page is the cleaner product-facing entry point: what the atlas is, how agents should use it, and where the system goes next.

01

Classify the layer

Route the task to UI, dependencies, containers, infrastructure, APIs, auth, AI tools, security, data, or internal policy before choosing a source.

02

Prefer authority

Use official registries, docs, package indexes, vendor references, and internal catalogs as implementation authority. Treat examples as discovery unless verified.

03

Expose risk

Return maintenance, license, pricing, secrets, data access, compatibility, and approval checks before the agent changes the codebase.
